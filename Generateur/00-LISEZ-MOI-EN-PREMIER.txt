🎯 DÉMARRAGE RAPIDE (3 MINUTES)
═══════════════════════════════════════════════════════════════════════

1. Ouvrez : START-HERE.md
2. Installez : npm install
3. Configurez : export API_KEY="votre_clé"
4. Testez : npm test
5. Générez : npm start

✅ C'est tout ! Vos images seront dans generated-images/
